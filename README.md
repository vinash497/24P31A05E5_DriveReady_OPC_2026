# 🤖 AI Agents – One Person Company

## 📌 Overview

This repository contains my learning journey, hands-on implementations, experiments, and projects developed as part of the **AI Agents – One Person Company (OPC) Training Program**.

The repository focuses on understanding and building AI-powered applications using Large Language Models (LLMs), AI agents, tool integration, memory, Retrieval-Augmented Generation (RAG), and multi-agent workflows.

The main objective is to gain practical experience in developing intelligent AI systems that can understand user requests, make decisions, use external tools, and perform tasks efficiently.

## 🚀 Projects and Implementations

### 1. Sweet Crumbs – AI Customer Support Assistant

An AI-powered customer support assistant designed for a bakery business.

**Key Features:**
- Answers customer queries based on bakery policies.
- Provides information about products and services.
- Collects necessary order requirements.
- Handles questions about eggless options.
- Generates concise and relevant responses.

**Technologies:** Python, LangChain, Groq API, GPT-OSS 120B.

### 2. Prompt Injection Detection

An AI-based implementation to identify suspicious prompts and potential prompt injection attempts.

**Key Features:**
- Analyzes user prompts for suspicious instructions.
- Identifies attempts to manipulate system instructions.
- Helps improve the security of LLM-based applications.

**Technologies:** Python, Groq API, Llama Prompt Guard 2.

### 3. AI Agent Workflows

Exploration and implementation of AI agent workflows.

**Key Concepts:**
- Tool calling
- Agent memory
- Retrieval-Augmented Generation (RAG)
- Workflow orchestration
- Task execution

### 4. Multi-Agent Systems

Exploration of systems where multiple specialized AI agents collaborate to complete complex tasks.

**Key Concepts:**
- Specialized agents
- Agent communication
- Supervisor-based coordination
- Task delegation
- Multi-agent orchestration

## 🔐 Security Practices

- Store API keys using environment variables.
- Never expose sensitive credentials in source code.
- Validate user inputs and model outputs.
- Apply safeguards when using external tools.
- Use human approval for sensitive or irreversible actions.
- Follow secure practices while developing AI-powered applications.
